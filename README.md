# NOVA — AI Productivity Platform

> **Build Better. Work Smarter.**

NOVA is a modern AI-powered productivity platform concept designed to help teams manage projects, automate repetitive work, and collaborate efficiently from one workspace.

This project was created as a **Front-End Development Intern Assignment** with a focus on modern UI/UX, responsive design, reusable React components, accessibility basics, and front-end interactions.
