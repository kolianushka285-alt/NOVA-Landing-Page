# NOVA — AI Productivity Platform

## Project Description
NOVA is a modern AI-powered productivity platform designed to help
teams manage projects, automate repetitive work, and collaborate efficiently.

## Technologies Used
- React
- Vite
- JavaScript
- HTML5
- CSS3

## Features
- Responsive navigation
- Mobile hamburger menu
- Hero section
- Trusted companies section
- 6 feature cards
- Product workspace dashboard
- How It Works
- Statistics
- Solutions / Use Cases
- 3 Testimonials
- 3 Pricing plans
- FAQ accordion
- Final CTA
- Footer
- Smooth scrolling
- Hover animations
